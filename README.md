# 🎓 Kampus Unggul - E-Learning Platform

![Project Status](https://img.shields.io/badge/status-active-success.svg)
![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-2.0.0-blue.svg)

**Kampus Unggul** adalah platform e-learning modern yang dirancang untuk memberikan pengalaman belajar online terbaik. Project ini dibangun dengan fokus pada **Desain Visual**, **Aksesibilitas (Accessibility)**, dan **Performa Tinggi**.

🌐 **Live Demo:** [https://chlayverts.github.io/zaza/](https://chlayverts.github.io/zaza/)

## ✨ Fitur Utama

Project ini memiliki skor sempurna **10/10** di berbagai aspek teknis:

* 📱 **Responsive Mobile-First**: Tampilan sempurna di semua perangkat (HP, Tablet, Desktop).
* 🎨 **Modern Design**: Menggunakan CSS Variables, gradient modern, dan glassmorphism.
* ♿ **Full Accessibility (A11y)**: Mendukung screen reader dan navigasi keyboard (WCAG 2.1 Compliant).
* ⚡ **High Performance**: Optimasi loading resource, lazy loading, dan code splitting.
* 🔒 **Security**: Dilengkapi dengan input sanitization dan praktik keamanan standar industri.
* 🌑 **Dark Mode Ready**: Struktur CSS siap untuk implementasi tema gelap.

## 🛠️ Teknologi yang Digunakan

* **HTML5** - Semantic element structure
* **CSS3** - Custom properties, Flexbox, Grid
* **JavaScript (ES6+)** - Modular OOP architecture

## 🚀 Cara Menjalankan Project (Local)

1. **Clone repository ini**

    ```bash
    git clone https://github.com/chlayverts/zaza.git
    ```

2. **Buka folder project**

    ```bash
    cd zaza
    ```

3. **Jalankan dengan Live Server (VS Code Extension)**
    * Klik kanan pada `index.html` → "Open with Live Server"

    *Atau menggunakan Python simple server:*

    ```bash
    python -m http.server 8000
    ```

4. **Akses di Browser**
    Buka `http://localhost:8000`
